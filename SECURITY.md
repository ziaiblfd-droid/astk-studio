# Security

## Research data

The GitHub Pages deployment is static and does not upload or store research data. Real datasets should only be submitted to an ASTK Studio backend operated by the researcher or an organization they trust.

## Public deployment

Before exposing the backend to the internet, configure HTTPS, authentication or quotas, resource limits, automatic data expiration, and operational logging. Do not deploy the prototype backend directly to the public internet without those controls.

## Reporting

Please report security issues privately to the repository maintainers rather than opening a public issue containing sensitive data.
